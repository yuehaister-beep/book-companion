# 人人都是一本书 · Book Companion

通过渐进对话，陪一个人把想法、经验或已有书稿，写成一本自己的书。

**状态：v0.1.0-alpha.1，Alpha 测试版。** 不是一键生成畅销书的服务；目前不包含服务器、账户、公共图书馆或独立多模型调度。没有获得 OpenAI 官方审核或背书。其他模型平台兼容性尚未验证。

项目地址：https://github.com/yuehaister-beep/book-companion

## 能做什么

- 结合已有表达确认成书脉络：缘起、问题、读者、主张、递进及章节职责。
- 直接写作或边学边写；保留作者声音，避免反复问卷。
- 多本书分别保存，不设置容易串稿的全局“当前书”。
- 导入可读文本、评审和续写；讨论与正文分开，作者采用才进入书稿。
- 读者、导师两个评审视角；同模型角色评审，不冒充独立专家。
- 初稿、初审、定稿及修订历史；版本校验和不可被脚本覆盖的旧定稿快照。

## 运行条件

首发目标：具备本地文件与命令执行能力的 Codex 环境，以及 Python 3.9+。保存脚本只用标准库，无需 pip、模型 API 密钥或本项目服务器。模型账户、额度及联网工具由宿主提供，技能开源不等于模型免费。

直接支持 UTF-8 TXT/Markdown；Word、PDF、OCR、联网事实查证依赖宿主已有工具，不能保证每个环境可用。缺少文件能力时可对话，但不提供可靠的本地持久保存。

## 安装和开始

下载项目到本地后，可以请 Codex：

> 请把这个本地项目的 skills/book-companion 安装到本机实际支持的技能位置，并保留 LICENSE；已存在同名版本时先核对，不要覆盖我的书稿。

也可以把 `skills/book-companion` 整个目录放到宿主识别的个人技能目录。当前官方文档列出用户位置 `~/.agents/skills`，项目位置 `.agents/skills`；部分已有安装使用 `~/.codex/skills`，应以实际宿主为准，不要同时装两份同名技能。[官方安装与发现规则](https://learn.chatgpt.com/docs/build-skills)

安装后确认技能列表能找到“人人都是一本书”，不能发现时重启宿主再检查。未完成宿主加载实测前不要把文件复制成功当成安装成功。

示例调用（目录由你选择，放在技能包和公开仓库以外）：

> 使用 $book-companion。我想写一本给新手老师看的经验书，请先理解我已有的经历，逐步讨论成书脉络，不要一次问我很多问题。

> 使用 $book-companion。继续 `/我的私人书房/教学经验` 这本书。先读取进度，再接着上一章写，不改另外一本书。

> 使用 $book-companion。先分析我指定的这份 Markdown 原稿，展示章节归属预览，不要覆盖原文件，也不要直接定稿。

## 文件与隐私

每本书的 `.book-companion.json` 是权威状态，包含正文、版本、候选、决定与工作记忆；Markdown 导出是阅读副本。备份请备份整个书籍项目目录。升级技能不需要迁移或覆盖书稿。

本项目脚本不联网、不上传、不遥测；但宿主 AI 可能将被选中的书稿发送给其模型服务。这不是离线保密方案。不要在公开 Issue 上传原稿、聊天记录、密钥或完整状态文件。详见 [隐私与安全](PRIVACY.md)。

开源许可证适用于本仓库技能、代码和文档，不要求使用者公开自己的书稿，也不保证生成内容的原创性或权利归属。

## 已知限制

- 本地单用户，不是协作服务器；锁冲突会停止，不自动强行解锁。
- 自动检查不能认证作者意图，也不能识别所有被错误标记为正文的聊天；宿主须忠实执行确认协议。
- 目录可新增、改名、重排，暂不提供删除已有章的命令。
- 批量导入逐项提交，不是全批原子操作；失败需报告已成功范围。
- JSON 包含全部历史，十万字以上长稿的性能、长程记忆和检索尚未实测。
- 读者/导师反馈不是独立专业审稿；没有版权认证、疗效保证或“写完即专家”的承诺。
- 状态回归测试不等于对话质量通过，实测边界见 [测试说明](docs/TESTING.md)。

## 开发与反馈

在项目根目录运行：

```sh
python3 -m unittest discover -s tests -v
python3 tools/build_release.py --output-dir /一个新的本地输出目录
```

发布包只包含显式白名单文件，并生成 SHA-256 清单，不打包个人书籍。发布流程见 [发布清单](docs/RELEASE.md)。

反馈请使用脱敏、可复现的小示例。更新时保留作者控制权、跨书隔离和版本保护，详见 [贡献约定](CONTRIBUTING.md)。
