## 可复现回归

在仓库根运行 `python3 -m unittest discover -s tests -v`。

覆盖：项目独立 id、跨书拒绝、候选与正文隔离、明确采用、旧版本/指纹冲突、幂等重试、目录改名重排、三个合成片段、定稿快照、定稿后修订、多次定稿、模式切换、记忆接续、锁与符号链接、CLI 保存失败不写入、导出不覆盖、发布白名单与校验和。

不覆盖：模型是否始终正确理解作者、自动选择技能是否正确、十万字长稿表现、不同平台加载、PDF/OCR 质量、专业事实审稿、真实多模型独立性、实际 GitHub/官方目录安装。通过代码测试不代表这些能力已经通过验收。
