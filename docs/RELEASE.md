## 官方目录（独立步骤）

不以 GitHub 发布成功冒充官方目录上架。后续需将技能封装为插件，确认当前格式，并完成：

- 发布者身份验证和提交权限（由账号持有人完成登录/身份验证）。
- 名称、简介、标识图、网站/支持地址、隐私与条款地址。
- 最终技能包、真实启动示例、五个正向和三个负向测试用例。
- 可用地区、版本说明、扫描问题修复、提交审核。
- 获批后由发布者选择公开，并验证用户侧可发现与安装。

不能在没有真实测试证据时勾选已经测试，不能代替用户完成身份声明或承诺审核时间。第一版不需要远程 MCP 服务器。
